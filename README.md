### 🎼 Featured project: [Maestro](https://maestro.condorsoft.dev)

A free macOS app for running and supervising many Claude Code sessions at once. Built with Claude Code itself.

- **Orchestrator panel** that reads the live state of every session and answers one question: *which sessions need me right now?*
- **Rules-based inbox** that ranks sessions waiting on a human, with no model call. Plus silent-agent detection.
- **Git worktree per session**, context and usage-limit monitoring with auto-continue.
- Sessions can be started and chained with rules. Every action is logged and user-approved.
- Optional **remote mode over Tailscale**.
